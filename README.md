# Site da 7A Produtora

Site estático publicado no Cloudflare (Workers com arquivos estáticos). Cada push na branch `main` publica de novo.

- `public/`: o site (index.html, páginas dos artistas, img/, midia/).
- `ferramentas/`: gerador das páginas de artista (`gera_artistas.py` + `artista.css`) e especificação da carta do casting.
